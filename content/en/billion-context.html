billion-context is an open-source proxy: your agent talks to it instead of its model, and it rewrites the conversation on the way, giving the model tools to compress and recall what is old. The promise is long sessions without hitting the window. We do not adopt a tool on a promise: we measured it on the three agents we use.

What you get. A clear answer before you spend an evening on it: no gain under about 100,000 tokens of context, a real extra cost in some cases, and the safe way to install, plug in and remove it if you want to try on long sessions.

1. Install it tightly

  • Pin the version and install without running package scripts (npm install --ignore-scripts): its only dependency is a validation library.
  • Run it as a user service bound to the machine itself, with NoNewPrivileges and ProtectSystem=strict.
  • Turn off automatic updates and the "check for news" calls in its configuration.

2. Plug it in, one agent at a time

  • Claude Code: point ANTHROPIC_BASE_URL at the proxy, with a direct fallback if it does not answer. Works with a subscription; no token appears in its log.
  • Kimi Code: changing the address does not work, because Kimi stores its login under a key derived from that address, and loses it. Use the proxy's native plugin instead: it adds a separate provider that keeps the same login key.
  • OpenFox: one switch, the model address it uses.

3. What we measured

Verdict: under about 100,000 tokens, nothing to gain and a small cost (its own tool descriptions add about 17 KB to each request). Its expected effect is on small local windows, 32k to 64k, on very long sessions: still to be shown. We put every agent back on its direct route.

Traps

A proxy that rewrites the prompt breaks the provider's prompt cache. On a subscription billed by tokens, that alone can triple a bill.

Do not copy an agent's login token to make a proxy work: tokens that renew themselves can invalidate the original. Use a mechanism that shares the existing login.

Keep a one-line way back: an environment variable or plugin remove. Ours were used the same evening.
