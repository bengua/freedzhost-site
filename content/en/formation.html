The freedzhost training: learn to develop your own code, assisted by AI, on your own machine — not depend on an AI that codes for you.

The doctrine

Coding with AI is good. Developing your own code assisted by AI is stronger.

Coding with AI ("vibe coding"): you describe, the AI generates, you paste. It works for a Sunday prototype. But the day it breaks — and it does — you debug code you did not write, do not understand, and that the AI no longer understands after the third generation.

Developing assisted by AI: you lay out the architecture, you write the decisions, you read every diff — and the AI does what it does best: speed, tests, documentation, variants. The model proposes, the code decides, and you arbitrate. That is the posture we teach, because it is the one that lasts: code you understand gets fixed, code you suffer gets paid for.

Prerequisites

No developer level required. However, you need the basics — and each one is already covered by a free tutorial on the site:

  • A terminal and not being afraid of it — reading an error, running a command, understanding what a file path is.
  • Git, just enough — save, roll back, read a change. (Forgejo CI tutorial.)
  • Knowing what a server at home is — a running machine, a port, a local IP. (Hardware, Homelab Proxmox.)
  • A local model that answers — the first ollama run or llama.cpp. (First model tutorial.)
  • The curiosity to read what the AI writes — this is the prerequisite we cannot tutorial-ize; the rest can be learned.

Each training module starts by checking these basics with you, and points to the free tutorial that fixes them if they are missing.

What if code puts you off?

No desire — or no time — to learn languages? It is not an end, it is a different path, and it is honorable. Self-hosted no-code tools already do almost everything:

  • n8n — block-based automation: connect services, local models, webhooks, without writing a line. (Already covered by our tutorials.)
  • PocketBase / Baserow — a database and auth with a real admin interface: your member area, your lists, your content.
  • Appsmith / Tooljet — drag-and-drop internal interfaces, connected to your data.
  • Home Assistant — whole home automation through visual automations.
  • WordPress / static + forms — to publish without developing.

Our honest position: no-code takes you far, and the training takes you there too — several modules are entirely playable in no-code. But every coding concept you accept to understand (not write: understand) multiplies what no-code can do for you. A prompt that knows what an API, a webhook, or a database is gets results from AI that a prompt without vocabulary will never get. So we offer two doors, and they meet.
