Every technical word used on this site, in alphabetical order, explained without jargon. If a tutorial loses you on a word, it is probably here.

Agent
A program driven by an AI model that does not only answer but acts: it reads files, runs commands, opens pull requests. See Giving code work to a local agent.
API
A door through which one program asks another for something, with a fixed format. "OpenAI-compatible API" means the format most AI tools already speak.
Backup
A copy you can restore. A copy you have never restored is not yet a backup. See Homelab 5.
Certificate (HTTPS)
The digital ID card that lets a browser show the padlock. Let's Encrypt gives them for free. See Homelab 2.
CI (continuous integration)
A machine that runs the tests automatically on every proposed change, and says green or red. See Homelab 8.
Container
A program packed with everything it needs, isolated from the rest of the machine. You start it, stop it, delete it without leaving traces. Docker is the usual tool.
Context
How much text a model can keep in mind at once, counted in tokens. More context needs more VRAM.
Compose (Docker Compose)
A small text file that describes one or several containers and how to start them, so that one command brings everything up.
DNS
The internet's phone book: it turns a name like freedzhost.cloud into an address. See Homelab 4.
GGUF
The file format of models for llama.cpp. One file holds the whole model, already compressed.
GPU / graphics card
The card that computes images, and AI models, very fast. Its own memory is the VRAM.
Homelab
Your own small data centre at home: one or a few machines running the services you would otherwise rent.
Hypervisor
Software that splits one physical machine into several virtual ones. Proxmox is one. See Homelab 1.
LLM (large language model)
An AI model that reads and writes text. "Local" means it runs on your machine, not on someone's cloud.
Model (weights)
The trained AI itself, a big file of numbers. "8B" means eight billion parameters: bigger is usually smarter and always heavier.
OCR
Reading text in an image: turning a scan into words you can search. See Homelab 12.
Open source
Software whose code anyone can read, modify and share. "Fair-code" or "source available" is close, but with restrictions.
Port
A numbered door on a machine. A web site usually answers on 443. Each open port is a door to keep closed unless it is needed.
Private network (VPN)
An encrypted tunnel between your own devices, so your phone reaches home as if it were on the home Wi-Fi. See Homelab 6.
Proxy (reverse proxy)
The single entrance of your homelab: it receives every visitor, holds the certificates, and passes each request to the right service. See Homelab 2.
Pull request (PR)
A proposed change to code, waiting to be reviewed and merged. Nobody, human or agent, should change the main branch without one.
Quantisation (Q4, Q8…)
Compressing a model by storing its numbers with fewer bits. Q4 is smaller and a little less precise than Q8.
RAG
Letting a model answer from your own documents: the relevant passages are found first, then given to the model with the question.
Self-hosted
Run on your own machine instead of rented from a company.
Token
The unit a model reads and writes: roughly a short word or a piece of a word. Speeds are counted in tokens per second.
VM (virtual machine)
A complete computer simulated inside a real one, with its own system. Many VMs can share one physical machine.
VRAM
The graphics card's own memory. A model runs fast only if it fits in it. See Hardware, honestly.
Webhook
An address that triggers something when it is called. Sign it, or anyone who finds it can trigger it.
