SearXNG is an open-source metasearch engine: you ask it, it asks Google, Bing, DuckDuckGo, Wikipedia and dozens of others, and merges the answers. The engines see your server, not you: no account, no history tied to your name. And for an agent network it does one more thing: it answers in JSON, so your local agents can search the web without any API key.

1. Run it

The SearXNG project maintains a ready-made Docker setup (the searxng-docker repository). Follow it, publish the service through your HTTPS proxy (Homelab 2) or keep it on your private network (Homelab 6), and set your browser's default search engine to it.

2. Two settings that matter

In settings.yml, change server.secret_key to a long random value: SearXNG refuses to start with the default one, on purpose.

Then, for your agents, allow the JSON format next to HTML:

search:
  formats:
    - html
    - json

An agent can now call https://search.yourdomain.tld/search?q=…&format=json and read the results.

Traps

A public SearXNG with JSON enabled is a free search API for every bot on the internet, and the engines will soon block your server for the traffic. Keep the JSON instance on your private network, or turn on SearXNG's limiter.

Some engines block or throttle shared instances from time to time. When one engine's results disappear, check its status in the preferences page before suspecting your setup.
