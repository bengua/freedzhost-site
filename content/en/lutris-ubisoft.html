Moving to Linux, the question always comes: "and my games bought elsewhere than Steam?" They come back from your accounts, not from your old disk. Lutris installs each publisher's launcher inside its own Windows environment, run by Proton, the same compatibility layer Steam uses. You sign in, you download, you play.

What you get. Ubisoft Connect running on Linux in one installer, with three large games installed (Assassin's Creed Valhalla, Immortals Fenyx Rising, Star Wars Outlaws: 165 GB in all) and more than thirteen hours played.

1. Lutris, not Heroic, for Ubisoft and EA

Heroic is excellent for GOG, Epic and Amazon, but it does not handle Ubisoft or EA. Lutris covers all of them, with community installers that do the fiddly steps for you. Install it with the pieces Wine needs to run Windows installers and the game mode helper:

# Arch-based (CachyOS, EndeavourOS); same names on most distributions
sudo pacman -S lutris umu-launcher wine-mono wine-gecko gamemode lib32-gamemode

umu-launcher runs Windows programs through Proton outside Steam, with the same fixes Steam applies.

2. Put the library where there is room

One game weighs 30 to 70 GB. Before installing anything, point Lutris at a disk with space, in Preferences → System → Default installation folder, which writes:

# ~/.config/lutris/system.yml
system:
  game_path: /mnt/games

3. Install the launcher

In Lutris, search "Ubisoft Connect", pick the installer marked Latest, and let it run. Here is what it does, so you know what to check if it fails:

  1. creates a 64-bit Windows prefix (its own C: drive) in your library folder;
  2. adds two Windows components games expect: d3dcompiler_43 and the core fonts;
  3. downloads the official installer and runs it silently;
  4. writes a settings file that turns off the launcher's overlay, a frequent source of crashes and stutters under Proton.

Sign in to your account in the launcher, then install your games from it, as on Windows. They land inside the prefix, on your big disk.

4. Play from the sofa

The tower has no screen here: games are streamed to an Android handheld with Moonlight (see the gaming PC that became an AI server). Launch Lutris from the streamed desktop, or add the launcher to the stream's application list.

Traps

Nothing to recover from an old Windows disk: launchers redownload from your account. We looked: 278 GB of old backups held emulators and tools, not a single PC game.

Opening Lutris remotely? Never through systemd-run --user --collect: closing Lutris then killed the launcher, the running game and an 84 GB download half-way. Start it detached with the session's environment (see SSH for an agent workstation).

On a machine that also serves AI models, a game needs its card back. Let the game take a card only while you play (see free your cards for AI, and still play).
