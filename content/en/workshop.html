Everything described on this site runs on tools we wrote, small and single-purpose, one repository each. Here they are by job, one sentence each, with the tutorial that shows them at work. Most are licensed MIT, a few GPL or AGPL; the ideas are free to take in any case.

What you get. The map of a complete, sovereign agent stack, from the GPU allocator to the phone console. Find the brick you need, then follow its tutorial.

Consoles and agents

  • Inari: the phone console of the whole stack, native Android, plus its small API (tutorial).
  • CloudFoxRoom: durable, replayable conversations across several agent instances (tutorial).
  • foxroom and FoxDesk: an open-source agent core, unpatched, with our adapters, and its desktop client (tutorial).
  • fh-dev: hand a development task to a local coding agent; it comes back as a pull request (tutorial).
  • fh-assistant: a workstation assistant that points at a function and never types (tutorial).
  • fh-coder-mode: how Claude Code is wired and tuned here, with the measured settings and the failures already paid for.

Models and cards

  • turnstile: a deterministic GPU allocator for local models (tutorial).
  • kvmem-llama-cpp: our build of KVMem for long contexts, two card generations, experts in host memory (tutorial).
  • fh-bench: a measured map of what each local model can be asked (tutorial).
  • fh-judge: a local decision judge in two passes, Tev1 then Nimble (tutorial).
  • Strata (not ours, integrated here): Flash-Next on one gaming card, as one more slot of the grid (tutorial).
  • billion-context (not ours, measured here): a context-compression proxy, and why we did not keep it (tutorial).
  • fh-egpu: reports the PCIe link the firmware really gave each card (tutorial).

Watch, diagnose, prove

  • fh-why and fh-probes: facts for a diagnosis, and a machine that remembers what it lived through (tutorial).
  • fh-detective and fh-mutant: a judge that designates where to look, and mutations that prove a test is useful (tutorial).
  • fh-rag-service: a local, deterministic search over your own journal (tutorial).
  • knowledge-packs: facts with a source, a test and an expiry date (tutorial).
  • parc: inventory your machines by scanning, and see what moved (tutorial).

Forge and deployment

  • fh-deploy: a root daemon that deploys one component from a closed list, without a password (tutorial).
  • forgejo-bootstrap: from a new repository to its first release in one call, never without its guard (tutorial).
  • fh-push and fh-forge-tools: publish a branch as a pull request through the forge helper.
  • fh-backups: keeps an off-machine copy of the hypervisor's nightly backups (tutorial).
  • fh-compute: rebuild the workstations from a declaration (tutorial).

Desk, sound and fun

  • purrd: music while the agent works, silence when it is done (tutorial).
  • inframagotchi: a manga cat whose health is your homelab's (tutorial).
  • claude-archive: your Claude.ai history as files, nothing lost (tutorial).
  • openfox-omarchy: a context meter in the status bar (tutorial); and Omarchy itself, in depth (tutorial).
  • fh-kill: stop processes by pattern without killing your own shell (tutorial).

Studio and voice

  • fh-seq: a local music studio that keeps the project (tutorial).
  • ACE-Step (not ours, used daily): three minutes of music in 27 seconds (tutorial).
  • studio-media: from one sentence to images and video shots (tutorial).
  • house-voice: the house's speech for Home Assistant, local (tutorial).
  • fh_voice_coder_console: talk to your local coding agent from your phone; alpha.

Doctrine and tools

  • The deterministic doctrine: the model proposes, the code decides (tutorial).
  • fh-tools: fourteen deterministic tools for coding agents (tutorial).
  • The fh- suite: sixty small commands that run the lab (tutorial).
  • Creation: the whole studio, from images to films (tutorial), and ArtCraft built from source (tutorial).

Learning

  • tutorat: a learning method and a local Socratic tutor that never gives the answer: it names the error and guides the fix.
  • freedzhost-site: this site, bilingual, generated by one script, drawings in code.
