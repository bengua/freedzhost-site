Imaginez. Vous êtes sur le canapé. Sur votre téléphone, vous ouvrez une seule appli. Vous demandez à un agent de code de réparer un test sur le serveur, vous le regardez travailler ligne à ligne, vous validez sa commande d'un tap. Une notification vous dit que le rendu d'image commandé il y a une heure est prêt. Une autre, que la machine de garde vient de bannir une adresse qui scannait votre proxy. Tout ça sur votre matériel, sans facture mensuelle au jeton.

Ce qu'un seul client vous permet

  • Coder sur chaque machine. Ouvrez une session OpenFox sur n'importe laquelle de vos machines, suivez-la en direct, intervenez, validez. Les tâches longues partent chez Kimi Code, les délicates chez Claude Code, celles du quotidien restent locales et gratuites.
  • Garder le fil. Les salles survivent à l'appli fermée, au réseau perdu, au changement d'écran : commencez sur le portable, finissez sur le téléphone.
  • Créer. Images, plans vidéo, objets 3D avec ComfyUI sur vos propres cartes, commandés par un agent qui remplit un workflow testé.
  • Veiller sur le labo. La machine de garde (proxy, fail2ban), les erreurs, les sauvegardes, quel modèle est sur quelle carte : tout dans un résumé, les alertes poussées par ntfy.
  • Décider, d'un tap. L'orchestrateur local lit tout seul et propose ; rien n'agit sans votre tap sur une carte (voir SwarmFox).

Pourquoi ça reste simple

Le concept est ambitieux ; les briques ne le sont pas. Trois règles le garantissent :

  1. Des petites pièces, un rôle chacune. Une API qui lit, un contrôleur qui garde les conversations, des agents qui codent. Chacune tient dans la tête, chacune se remplace.
  2. Le modèle propose, le code décide. Verdicts, fusions et actions sont de simples programmes ou votre tap, jamais l'humeur d'un modèle (voir BMAD avec de petits modèles).
  3. Une seule passerelle vers tous les modèles. Changez de modèle, de carte ou de fournisseur : rien d'autre ne bouge (voir la passerelle de modèles).

Par où commencer

On ne le construit pas d'un bloc. Commencez par la passerelle et OpenFox : une soirée, et vous avez déjà un agent de code local. Chaque tutoriel suivant ajoute une brique qui marche toute seule.
