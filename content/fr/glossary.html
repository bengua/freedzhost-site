Chaque mot technique de ce site, par ordre alphabétique, expliqué sans jargon. Si un tuto vous perd sur un mot, il est sans doute ici.

Agent
Un programme piloté par un modèle d'IA qui ne se contente pas de répondre mais agit : il lit des fichiers, lance des commandes, ouvre des pull requests. Voir Confier du code à un agent local.
API
Une porte par laquelle un programme demande quelque chose à un autre, dans un format fixé. « API compatible OpenAI » désigne le format que parlent déjà la plupart des outils d'IA.
Auto-hébergé
Qui tourne sur votre propre machine au lieu d'être loué à une entreprise.
Certificat (HTTPS)
La carte d'identité numérique qui fait afficher le cadenas au navigateur. Let's Encrypt les donne gratuitement. Voir Homelab 2.
CI (intégration continue)
Une machine qui lance les tests automatiquement à chaque changement proposé, et dit vert ou rouge. Voir Homelab 8.
Compose (Docker Compose)
Un petit fichier texte qui décrit un ou plusieurs conteneurs et comment les lancer, pour qu'une seule commande démarre tout.
Conteneur
Un programme emballé avec tout ce dont il a besoin, isolé du reste de la machine. On le démarre, l'arrête, le supprime sans laisser de traces. Docker est l'outil habituel.
Contexte
La quantité de texte qu'un modèle peut garder en tête d'un coup, comptée en jetons. Plus de contexte demande plus de VRAM.
DNS
L'annuaire d'Internet : il transforme un nom comme freedzhost.cloud en adresse. Voir Homelab 4.
GGUF
Le format de fichier des modèles pour llama.cpp. Un seul fichier contient tout le modèle, déjà compressé.
GPU / carte graphique
La carte qui calcule les images, et les modèles d'IA, très vite. Sa propre mémoire, c'est la VRAM.
Homelab
Votre petit centre de données à la maison : une ou quelques machines qui font tourner les services que vous loueriez sinon.
Hyperviseur
Un logiciel qui découpe une machine physique en plusieurs machines virtuelles. Proxmox en est un. Voir Homelab 1.
Jeton (token)
L'unité que lit et écrit un modèle : à peu près un mot court ou un morceau de mot. Les vitesses se comptent en jetons par seconde.
LLM (grand modèle de langage)
Un modèle d'IA qui lit et écrit du texte. « Local » veut dire qu'il tourne sur votre machine, pas dans le cloud de quelqu'un.
Modèle (poids)
L'IA entraînée elle-même, un gros fichier de nombres. « 8B » veut dire huit milliards de paramètres : plus gros est en général plus malin, et toujours plus lourd.
OCR
Lire le texte dans une image : transformer un scan en mots qu'on peut chercher. Voir Homelab 12.
Open source
Un logiciel dont n'importe qui peut lire, modifier et partager le code. « Fair-code » ou « source disponible », c'est proche, mais avec des restrictions.
Port
Une porte numérotée sur une machine. Un site web répond en général sur le 443. Chaque port ouvert est une porte à garder fermée sauf besoin.
Proxy (proxy inverse)
L'entrée unique de votre homelab : il reçoit chaque visiteur, garde les certificats, et passe chaque requête au bon service. Voir Homelab 2.
Pull request (PR)
Un changement de code proposé, en attente de relecture et de fusion. Personne, humain ou agent, ne devrait modifier la branche principale sans en passer par là.
Quantification (Q4, Q8…)
Compresser un modèle en stockant ses nombres sur moins de bits. Q4 est plus petit et un peu moins précis que Q8.
RAG
Faire répondre un modèle à partir de vos propres documents : on retrouve d'abord les passages utiles, puis on les donne au modèle avec la question.
Réseau privé (VPN)
Un tunnel chiffré entre vos propres appareils, pour que votre téléphone rejoigne la maison comme s'il était sur le Wi-Fi. Voir Homelab 6.
Sauvegarde
Une copie que l'on sait restaurer. Une copie jamais restaurée n'est pas encore une sauvegarde. Voir Homelab 5.
VM (machine virtuelle)
Un ordinateur complet simulé dans un vrai, avec son propre système. Plusieurs VM peuvent se partager une machine physique.
VRAM
La mémoire propre de la carte graphique. Un modèle ne tourne vite que s'il y tient. Voir Le matériel, honnêtement.
Webhook
Une adresse qui déclenche quelque chose quand on l'appelle. Signez-la, sinon quiconque la trouve peut la déclencher.
