Trois services web couvrent beaucoup de besoins du quotidien. Une fenêtre de discussion pour vos propres modèles, pour que la famille ne colle pas de choses privées dans un chatbot public. Une boîte à outils PDF, pour que contrats et fiches de paie ne partent pas sur des convertisseurs « gratuits ». Et la transcription, pour qu'une réunion ou un mémo vocal devienne du texte sans quitter la maison.

Ce que vous y gagnez. De quoi remplacer un abonnement à un chatbot, les convertisseurs PDF en ligne et les services de transcription, sur vos propres machines, et les trois réglages qui les gardent à vous.

1. Open WebUI : une discussion privée avec vos modèles

docker run -d --name openwebui -p 127.0.0.1:3000:8080 \
  -v openwebui:/app/backend/data \
  -e WEBUI_AUTH=true -e ENABLE_SIGNUP=false \
  -e OLLAMA_BASE_URL=http://votre-serveur-de-modeles:11434 \
  ghcr.io/open-webui/open-webui:main
  • Il parle à Ollama, ou à votre passerelle de modèles en connexion compatible OpenAI : chaque modèle que vous servez apparaît dans la liste.
  • La recherche web peut passer par votre propre SearXNG, pour que les questions d'actualité restent privées elles aussi.
  • Créez les comptes vous-même, puis laissez l'inscription fermée.

Nous l'avons fait tourner des mois, puis retiré : nos propres clients font désormais le travail : SwarmFox sur Android et FoxDesk sur PC, qui parlent aux mêmes modèles par la même passerelle. Ses journaux ont montré une chose à savoir : publié sur internet, presque toutes ses requêtes venaient de scanners automatiques, pas de nous. Si seul votre foyer s'en sert, atteignez-le par votre réseau privé et ne le publiez pas du tout.

2. Stirling-PDF : tous les outils PDF, hors ligne

docker run -d --name stirling-pdf -p 127.0.0.1:8081:8080 \
  -v stirling-configs:/configs \
  -e DOCKER_ENABLE_SECURITY=true \
  stirlingtools/stirling-pdf:latest

Fusionner, découper, faire pivoter, compresser, convertir, signer, et passer à l'OCR des documents scannés avec Tesseract, dans le navigateur, sans que les fichiers quittent votre réseau. Avec la sécurité activée, il demande une connexion ; changez le mot de passe initial dès la première connexion.

3. Scriberr : des enregistrements au texte

Déposez un fichier audio, obtenez une transcription horodatée, produite par WhisperX sur votre propre machine. Le nôtre tourne à côté des cartes graphiques, attaché à la machine elle-même, et s'atteint par le réseau privé en HTTPS, seule origine qu'il accepte.

docker run -d --name scriberr --network host \
  -e HOST=127.0.0.1 -e PORT=8080 \
  -e ALLOWED_ORIGINS=https://votre-machine.votre-tailnet.ts.net:8080 \
  -v scriberr-data:/app/data -v scriberr-whisperx:/app/whisperx-env \
  ghcr.io/rishikanthc/scriberr:v1.2.0

Les trois mêmes réglages pour les trois

  1. Attachez-les à la machine elle-même (127.0.0.1) et publiez-les par votre proxy inverse ou votre réseau privé, jamais en ouvrant le port à tout le monde.
  2. Connexion activée, inscription fermée. C'est vous qui créez les comptes.
  3. Épinglez une version plutôt que latest ou main pour ce qui compte, pour qu'une mise à jour arrive quand vous le décidez.

Pièges

Ne coupez pas la vérification des certificats pour faire « marcher » un chargeur web : vous accepteriez n'importe quelle réponse de n'importe quel imposteur. Corrigez plutôt le certificat.

Donnez par défaut le rôle le plus restreint aux nouveaux utilisateurs. Une interface où chaque nouveau compte est administrateur n'est qu'à une invitation égarée d'un problème.
