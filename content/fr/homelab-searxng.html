SearXNG est un métamoteur de recherche open source : vous l'interrogez, il interroge Google, Bing, DuckDuckGo, Wikipédia et des dizaines d'autres, et fusionne les réponses. Les moteurs voient votre serveur, pas vous : ni compte, ni historique lié à votre nom. Et pour un réseau d'agents, il fait une chose de plus : il répond en JSON, donc vos agents locaux peuvent chercher sur le web sans aucune clé d'API.

Un peu d'histoire

searx, né en 2014, est un métamoteur : il envoie votre recherche à de nombreux moteurs à la fois et fusionne les réponses, sans vous profiler. SearXNG, un fork entretenu lancé en 2021, a poursuivi l'idée. Hébergé à la maison, il devient aussi l'outil de recherche de vos agents locaux, sans clé d'API ni quota.

1. Le lancer

Le projet SearXNG maintient une installation Docker toute prête (le dépôt searxng-docker). Suivez-la, publiez le service par votre proxy HTTPS (Homelab 2) ou gardez-le sur votre réseau privé (Homelab 6), et faites-en le moteur de recherche par défaut de votre navigateur.

2. Deux réglages qui comptent

Dans settings.yml, changez server.secret_key pour une longue valeur aléatoire : SearXNG refuse de démarrer avec celle par défaut, exprès.

Puis, pour vos agents, autorisez le format JSON à côté du HTML :

search:
  formats:
    - html
    - json

Un agent peut maintenant appeler https://search.votredomaine.tld/search?q=…&format=json et lire les résultats.

Pièges

Un SearXNG public avec le JSON activé est une API de recherche gratuite pour tous les robots d'Internet, et les moteurs bloqueront vite votre serveur pour ce trafic. Gardez l'instance JSON sur votre réseau privé, ou activez le limiteur de SearXNG.

Certains moteurs bloquent ou ralentissent de temps en temps les instances partagées. Quand les résultats d'un moteur disparaissent, vérifiez son état dans la page des préférences avant de soupçonner votre installation.
