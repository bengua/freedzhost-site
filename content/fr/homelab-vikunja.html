Vikunja est un gestionnaire de tâches open source : projets, listes, tableaux Kanban, échéances, rappels, et une app pour le téléphone. Il importe depuis Todoist et Microsoft To Do. Dans un réseau d'agents, il joue un rôle de plus : une file partagée, où les agents déposent ce qu'ils ont trouvé et où les décisions que seul un humain peut prendre vous attendent.

1. Le lancer

Vikunja tient dans un seul conteneur (interface web et API ensemble). SQLite suffit pour un foyer ; PostgreSQL si plusieurs personnes l'utilisent beaucoup. Réglez au minimum :

VIKUNJA_SERVICE_PUBLICURL=https://taches.votredomaine.tld/
VIKUNJA_SERVICE_SECRET=<une longue valeur aléatoire>

Publiez-le par votre proxy HTTPS (Homelab 2). Créez votre compte, puis fermez les inscriptions :

VIKUNJA_SERVICE_ENABLEREGISTRATION=false

2. Rapatrier vos listes

Dans vos réglages d'utilisateur, les outils de migration importent projets et tâches depuis Todoist ou Microsoft To Do. Faites-le une fois, vérifiez quelques listes, puis supprimez l'ancien compte.

3. Donner un jeton à vos agents, pas votre mot de passe

Dans Settings → API Tokens, créez un jeton par agent, avec une date d'expiration et seulement les droits dont il a besoin (par exemple : lire les projets, créer des tâches). Un agent peut alors déposer une tâche comme « Valider le nouveau calendrier de sauvegarde ? », et vous décidez depuis votre téléphone.

Pièges

Sans VIKUNJA_SERVICE_SECRET, Vikunja tire un secret au hasard à chaque démarrage : chaque redémarrage déconnecte tout le monde, et vous croirez à une panne. Réglez-le une fois.

Les inscriptions sont ouvertes par défaut. Sur un serveur joignable depuis Internet, fermez-les dès que vos comptes existent.

Un jeton par agent, jamais partagé : quand un agent se comporte mal, vous révoquez son jeton sans casser les autres.
