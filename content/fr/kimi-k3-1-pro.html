Moonshot AI vient de publier Kimi K3.1 Pro, le premier modèle de sa nouvelle série K3.1. Ce n'est pas un nouveau modèle de base : c'est Kimi K3, post-entraîné avec beaucoup plus de calcul, pour mieux coder, mieux tenir les longues tâches avec outils et moins inventer. Il garde un million de jetons de contexte, et ses poids seront publiés avant le 4 novembre.

En bref. Disponible dès maintenant sur Kimi (web et applis), Kimi Work, Kimi Code et l'API. Deux variantes : kimi-k3.1-pro et kimi-k3.1-pro-highspeed (2 à 3 fois plus rapide, même capacité annoncée, environ deux fois plus de quota consommé). Vérifié de notre côté : les deux identifiants répondent sur l'API, avec une fenêtre de 1 048 576 jetons.

Un peu d'histoire

Moonshot AI, fondée à Pékin en 2023, s'est fait connaître avec un assistant capable de lire de très longs documents. La série K2 a ensuite popularisé ses modèles auprès des développeurs, notamment pour le code et les agents. K3, sorti cet été, a porté un modèle à poids ouverts à 2,8 billions de paramètres (la « classe 3T » dont parle Moonshot). K3.1 Pro arrive environ trois mois plus tard : même base, entraînement de finition beaucoup plus poussé. C'est une tendance de fond de 2026 : une grande partie des progrès vient désormais de l'après-entraînement, pas seulement de la taille.

1. Ce qui est annoncé

  • Code et tâches longues : meilleurs résultats sur les bancs de terminal et de code au long cours.
  • Moins d'hallucinations : sur leur test interne le plus difficile, le taux d'affirmations fausses passe de 23,4 % (K3) à 8,3 %.
  • Création 3D et recherche financière : deux domaines mis en avant, avec une fonction « 3D Make » dans l'appli pour prévisualiser et imprimer des modèles 3D.
  • Raisonnement toujours actif : on ne peut pas le couper ; on règle son effort (low, high, max, par défaut max).
  • Poids ouverts avant le 4 novembre, sans les données d'entraînement liées à la cybersécurité offensive, retirées volontairement.

3. Combien ça coûte

  • API : 2 $ par million de jetons en entrée, 10 $ en sortie, 0,20 $ pour l'entrée déjà en cache (prix publiés via OpenRouter le 24 octobre 2026), sans palier selon la longueur du contexte. Sur la plateforme Moonshot, le modèle se débloque après une première recharge d'au moins 1 $.
  • Abonnement Kimi Code : K3.1 Pro à partir de l'offre Plus ; le million de jetons de contexte et la variante Highspeed à partir de l'offre Pro. Dans le terminal, on le choisit avec /model.

Piège relevé dans la documentation : dans un outil tiers, un identifiant mal tapé ne renvoie pas d'erreur, il bascule silencieusement sur un modèle plus ancien, sans raisonnement. Copiez l'identifiant exact : k3.1-pro dans Kimi Code, kimi-k3.1-pro dans l'API.

4. Ce que nous en faisons

Kimi Code est un de nos agents de tous les jours (voir notre tutoriel Kimi Code). Une leçon fraîche : l'abonnement a une limite mensuelle, et le jour où elle tombe, un agent qui ne dépend que de lui s'arrête. Chez nous, Kimi passe par une route de la passerelle qui retombe sur nos cartes graphiques puis sur des API gratuites quand le quota est épuisé (voir les routes auto-). Nous testerons K3.1 Pro sur nos tâches réelles avant d'en dire plus.
